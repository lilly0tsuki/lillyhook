# LillyHook
LillyHook is a completely hook-free mod for a voxel video game.

## Getting started
### Requirements
- **Zig 0.16.0** [Windows](https://ziglang.org/download/0.16.0/zig-x86_64-windows-0.16.0.zip)/[Linux](https://ziglang.org/download/0.16.0/zig-x86_64-linux-0.16.0.tar.xz)

### Setup
#### Building from source
```sh
# Assuming you already have git and zig installed
git clone https://github.com/lilly0tsuki/lillyhook.git
cd lillyhook
zig build
```

### Usage
1. Launch the game using the official launcher.
2. Inject lillyhook.dll using your preferred injector.
